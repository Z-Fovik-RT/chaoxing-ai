# 学习通 · AI智脑Pro

> 学习通 AI + 题库双引擎自动答题 & 刷课辅助用户脚本

**版本**：v1.3.4  
**兼容**：Chrome / Edge / Firefox + [ScriptCat](https://scriptcat.org/) / [Tampermonkey](https://www.tampermonkey.net/)  
**开源协议**：MIT

---

## 功能特性

### 核心功能
| 功能 | 说明 |
|---|---|
| **AI 自动答题** | 内置多个 AI Provider（OpenAI 兼容 / 文心一言 ERNIE 等），支持自定义 API Key 与模型，自动解析题目并作答 |
| **题库双引擎** | 内置题库 + AI 兜底，题库无结果时自动切换 AI 作答 |
| **划词搜题** | 选中页面文字即可唤起搜题面板，支持"换个模型重试" |
| **截图 OCR 搜题** | 对加密/图片题截屏自动 OCR 识别后搜题 |
| **作业/考试全自动** | 自动遍历题目、匹配答案、提交，支持重做模式覆盖旧答案 |
| **模型列表拉取** | 添加模型时可用接口地址 + API Key 直接拉取 `/v1/models`，点选标签自动填入，免手敲模型名 |
| **随堂练习** | 章节测验/随堂练习页（`/page/quiz/stu/answerQuestion`）自动作答，支持单选/多选/判断/填空/简答 |
| **复合大题子题** | 阅读理解、材料题等「一大题多小题」结构，自动带大题背景逐小题作答 |
| **视频/音频倍速** | 支持 1× / 1.25× / 1.5× / 2× 倍速播放 |

### 辅助功能
| 功能 | 说明 |
|---|---|
| **字体解密** | 自动解密学习通加密字体，还原题目原始文字 |
| **粘贴限制绕过** | 绕过学习通禁止粘贴限制，可直接从外部粘贴答案 |
| **题目一键复制** | 支持"复制纯文本（AI）"与"复制富文本（Word）"两种格式 |
| **章节自动导航** | 自动点击第一个未完成章节，开始刷课任务 |
| **反检测增强** | 劫持页面可见性/焦点检测，降低被平台风控概率 |
| **自动更新检查** | 面板内置更新按钮 + 24h 自动检查，发现新版本弹窗提醒 |

## 安装方法

### 方式一：从 GitHub 直接安装（推荐）

1. 安装 [ScriptCat](https://scriptcat.org/) 或 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 打开脚本安装链接：
   - [点击安装 `chaoxing-ai.user.js`](https://raw.githubusercontent.com/Z-Fovik-RT/chaoxing-ai/main/chaoxing-ai.user.js)
3. 在弹出页面点击"安装"

### 方式二：从本仓库手动安装

1. 克隆或下载本仓库
2. 在扩展中"添加新脚本"，将 `chaoxing-ai.user.js` 内容粘贴进去保存

## 配置说明

安装后脚本会注入一个浮窗面板，通过面板进行配置：

### AI 模型配置
1. 点击面板 **"模型管理"**
2. 添加 Provider（支持 OpenAI 兼容格式 / ERNIE 等）
3. 填入 API Key，选择模型
4. 多个 Provider 可设置优先级，AI 失败时自动切换下一个

### 刷课设置
| 设置项 | 说明 |
|---|---|
| 任务点任务 | 是否自动处理任务点 |
| 视频/音频 | 是否自动播放视频/音频 |
| 倍速 | 播放速度（1/1.25/1.5/2） |
| 测验自动处理 | 是否自动处理测验题 |
| 题库/AI 答题间隔 | 每题作答后的等待时长（ms） |
| 重做模式 | 不跳过已答题，重新 AI 作答覆盖旧答案 |
| 字体解密 | 推荐开启，自动还原加密字体题目 |
| 相似度匹配 | 精确匹配失败时使用相似度匹配选项 |

### 更新检查
- 点击面板右上角 **🔄 按钮** 手动检查更新
- 脚本每 24 小时自动检查一次（仅在顶层页面）
- 发现新版本后弹窗提醒，点击"立即更新"跳转安装

## 使用说明

### 自动刷课
1. 打开学习通课程页面
2. 脚本自动识别章节与任务点
3. 点击第一个未完成章节开始自动刷课
4. 浮窗面板可暂停/继续/跳转下一节

### 自动答题
- **作业/测验**：脚本自动识别题目类型，优先题库匹配，题库无结果则调用 AI
- **考试模式**：自动跳转下一题（可设置随机间隔）
- **手动搜题**：选中题目文字 → 点击浮动图标 → AI 或题库搜索

### 划词搜题
1. 在页面选中任意文字
2. 点击浮动搜索图标
3. 选择"AI 详细解答"或"题库搜索"
4. 不满意可点击"换个模型重试"

## 注意事项

1. **AI 功能费用**：使用 AI 答题需要自行提供 API Key，相关 API 费用由用户承担
2. **题库 Token**：题库功能需要付费 Token，由题库作者发放，本脚本仅提供接口对接
3. **推荐环境**：Chrome/Edge + ScriptCat，其他浏览器/扩展可能存在兼容性问题
4. **网络要求**：自动更新功能依赖 GitHub，国内访问不稳定时建议手动检查更新
5. **使用风险**：自动刷课/答题可能违反学校规定，请合理使用，后果自负

## 常见问题

**Q: 安装后脚本不生效？**  
A: 确认扩展已启用，页面 URL 匹配 `*://*.chaoxing.com/*` 或 `*://*.edu.cn/*`，刷新页面重试。

**Q: AI 答题返回答案太简单？**  
A: 在模型管理中将该模型设为"详细模式"，或更换支持长回答的模型（如 GPT-4、Claude 等）。

**Q: 题库没结果？**  
A: 检查题库 Token 是否有效，或关闭题库开关纯用 AI 作答。

**Q: 更新检查一直转圈？**  
A: 国内访问 GitHub raw 不稳定，可多试几次，或等待脚本自动重试（24h 间隔）。

## 更新日志

### v1.3.4
- **修复作业答题重复推进下一题**：`cxai_doHomeWork` 单选/多选/填空/判断/简答/写作/翻译/default 七个分支的 `.then()` 回调里，分支内已经推进了下一题，末尾又无条件再推进一次，导致同一道题被并发处理两遍、API/题库请求翻倍（N1 免费额度被白烧一半）、两个循环抢着点选项。现已去掉多余的重复推进，每题只推进一次。
- **修复考试主路径（`cxai_missonExam`）同类重复推进**：标准文本区、单选、多选、填空、判断、材料题富文本、脚本查找编辑器共 7 处 `cxai_toNextExam()` 被连发两次，会连点两次「下一题」导致跳题；现已收敛为单次推进。
- **修复整卷预览（`cxai_doExamPreview`）`err` 未定义**：7 个题型的 `.then()` 回调里引用了作用域外的 `err._paused`，运行时抛 `ReferenceError`，暂停重试逻辑整段失效、且产生未处理的 Promise rejection。现改为真正的 `.catch(function (err) { ... })`，暂停时按原题号 5 秒后重试，失败时正常跳过。
- 自动更新版本回退值同步到 1.3.4。
